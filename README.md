# zap-miniapp

## 英単語アプリ

### 概要

- **ゴールと現在地を可視化してくれることでモチベにつながる**
- 「あと、これだけ単語覚えればラクに解ける！」
- そんなアプリを目指しました。

### 使用API

- ログイン
- ニックネーム取得
- ニックネーム登録
- 利用履歴取得
- 利用履歴登録
- 利用履歴更新

### 起動手順

1. `git clone https://github.com/bcqureshi/zap-miniapp.git`で自分のPCに複製
2. `cd zap_miniapp/vite-project/`で実行ディレクトリまで移動
3. `npm install`で必要なライブラリをインストール
4. `npm run dev`で実行
