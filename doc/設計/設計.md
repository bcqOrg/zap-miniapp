# システム設計書

## 1. 画面設計

- **ログイン画面**
   ID入力 + PW入力 + ログインボタン + アラートエリア

- **HN設定画面（初回のみ）**
   ニックネーム入力 + 登録ボタン + ログアウトボタン + アラートエリア

- **ホーム画面**
   進捗グラフ + テスト開始ボタン + ログアウトボタン

- **単語テスト画面**
   出題単語 + 選択肢（4つ）+ アラートエリア

### 1.1. 画面遷移

- ログイン画面 -> HN設定画面 : ログインボタン押下時、かつ認証成功時、かつ初回ログイン時
- ログイン画面 -> ホーム画面 : ログインボタン押下時、かつ認証成功時、かつ2回目の以降のログイン時
- HN設定画面 -> ホーム画面 : 登録ボタン押下時、かつ登録成功時
- ホーム画面 -> 単語テスト画面 : テスト開始ボタン押下時
- 単語テスト画面 -> ホーム画面 : テスト終了時
- ホーム画面 -> ログイン画面 : ログアウトボタン押下時
- HN設定画面 -> ログイン画面 : ログアウトボタン押下時

### 1.2. UI設計

- 配色
  - メイン #28600E
  - サブ #E5E3D5
  - サブサブ #7D784A
- ボタン
  - 角は`14px`で丸める
  - ホバーで`1.05`倍に肥大
- 配置
  - 画面サイズは`1280*775`
  - 画面中央ぞろえ
  - ログイン画面の入力テキストボックスは縦に並べる、その下にログインボタン、その下にアラートエリア
  - HN設定画面の中央に入力テキストボックス、その下に登録ボタン、その下にログアウトボタン、その下にアラートエリア
  - ホーム画面の中央に進捗バーを表示、その下に開始ボタン、その下にログアウトボタンを配置
  - 単語テスト画面の中央に出題単語、その下に2*2のグリッドで選択肢、その下にアラートエリア
- アイコン
  - lucideのアイコンをボタンのテキストの左に配置

## 2. 技術構成

- **フロントエンド**
   Vite + React + JavaScript + TailwindCSS

- **ファイル構成**

   ```text

   src/
   ├─ App.jsx
   ├─ main.jsx
   ├─ components/
   │   ├─ Login.jsx        // ログイン画面
   │   ├─ HNSetup.jsx      // HN設定画面
   │   ├─ Home.jsx         // ホーム画面
   │   ├─ ProgressBar.jsx  // 進捗バー
   │   └─ Quiz.jsx         // 単語テスト画面
   ├─ data/
   │   └─ words.js         // 単語テストデータ

   └─ utils/
       ├─ crypto.ts        // 暗号化
       └─ signing-service.ts   // 認証

   ```

## 3. データ設計

### 3.1. データの保持方針

| データ | 保存場所 | 備考 |
|---|---|---|
| ユーザ認証情報（ログイン日時） | ローカルストレージ | セキュリティ確保のため |
| ユーザ情報（ID, ニックネーム） | サーバ | API経由で管理 |
| 利用履歴 | サーバ | API経由で管理 |
| 単語データ | 静的ファイル (`words.js`) | クライアント内で管理 |
| UI状態（選択肢、進行状況） | Reactのstate | 一時的に管理 |

---

### 3.2. データ構造例

#### ユーザ情報（ローカルストレージ）

```js
// ユーザ情報の保存例
const userInfo = {
  userId: "1234567890",       // ユーザID（例）
  nickname: "たろう",         // ニックネーム
  loginTime: "20240101120000" // ログイン日時
};

// ローカルストレージに保存
localStorage.setItem('userInfo', JSON.stringify(userInfo));

// 取得例
const storedUserInfo = JSON.parse(localStorage.getItem('userInfo'));
console.log(storedUserInfo);
```

#### 単語データ（静的）

```js
// src/data/words.js
export const words = [
  {
    id: 1,
    question: "Apple",
    options: ["リンゴ", "バナナ", "オレンジ", "イチゴ"],
    answer: 0
  },
  // 他の単語
];
```

---

### 3.3. 画面ごとのデータ管理

| 画面 | 管理データ | 備考 |
|---|---|---|
| ログイン | ユーザID | API呼び出しと連携 |
| HN設定 | ニックネーム | API登録・取得 |
| ホーム | 進捗情報・履歴 | APIから取得・表示 |
| ホーム | ログアウト状態 | ローカルストレージのユーザー情報を削除 |
| 単語テスト | 出題単語・選択肢 | 静的データ＋状態管理 |
