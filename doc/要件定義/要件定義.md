# ZAPによる英単語アプリ

## 課題背景

英語教師をやっているけど、いい英単語アプリがない

- mikan（UI、有名単語帳）
- duolingo（継続）
- HAMARU（音ゲー）
- WordHolic（共有）
- 英語漬け（継続）

語彙力は英語力の一番の土台
英単語学習は地道だけど継続がなにより重要
その人に合うアプリであることが重要なので、機能はシンプルでもいい

一番続いたのは[英語漬け](https://www.eigo-duke.com/tango/eiken3.html)、シンプルで無料、合格率（単語の学習カバー率）の可視化、音声、１０問単位で取り組みやすい、間違えた単語がいつでも見れる

要件として
~~「音声」~~
~~「例文」~~
「継続の可視化」
は欲しい

## 北村さんレビュー１回目

- コンテンツ置き場（Akamai）がないから公開コンテンツAPIは難しいかも -> 公開コンテンツをいったんなしで考える
- 学習履歴で英文を登録するのはアリだけど複雑
- 本来はコンテンツにもZAPを使うがローカルでいろいろやって設定保存アプリとしてもいい
- 出題意図としてログイン、ニックネーム程度でもいい -> いったんログイン機能だけ実装したい
- 残業なしで２週間で作れるサイズを見積もれ！-> フロント次第、ベネチャでどこまで作れるか

### 主要機能

1. ログイン
2. ニックネーム登録
3. 単語出題
4. 進捗・達成度可視化
5. 学習履歴の記録

### 要件をスリムに

- 学習範囲はあらかじめ設定した単語リスト
- 学習進捗はシンプルなグラフ
- 音声、例文は割愛
